# Trabalhos de Linguagens Formais e Autômatos

Cada trabalho é uma aplicação Next.js independente, na sua própria pasta.

| Pasta | Trabalho | Tema |
| --- | --- | --- |
| [`trabalho-1/`](trabalho-1/README.md) | Trabalho 1 · Exercício 6 | Conversão de AFND-ε em AFD e reconhecimento de sentenças |
| [`trabalho-2/`](trabalho-2/README.md) | Trabalho 2 · Exercício 3 | Gramática livre de contexto, Forma Normal de Chomsky e árvore de derivação |

## Executar

```bash
cd trabalho-1   # ou trabalho-2
npm install
npm run dev
```

Abra `http://localhost:3000`.
